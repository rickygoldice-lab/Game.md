# Gojo vs Sukuna — 3D Cinematic

A continuous, browser-based Three.js anime battle. It uses procedural characters and effects, so no external models or assets are required.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:8080`.

## Development server

```bash
npx serve .
```

The film starts automatically and lasts approximately 110 seconds. It has no menus or controls.
